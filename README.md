# New York City Airbnb Open Data Analysis Using Python

## 1. Project Definition

This project aims to analyse New York City Airbnb listings using Python. The analysis will include cleaning the dataset, handling missing values and duplicates, correcting data types, identifying outliers, and performing Exploratory Data Analysis (EDA).

The project will use data visualization techniques to understand rental prices, room types, neighbourhood distributions, and relationships between listing prices and reviews. The final output will include at least six visualizations and a short insights report.

## 2. Dataset Use Case

**Dataset:** New York City Airbnb Open Data (2019)

**Source:** Kaggle

**Dataset Link:** https://www.kaggle.com/datasets/dgomonov/new-york-city-airbnb-open-data

The dataset contains information about Airbnb listings in New York City, including prices, neighbourhoods, room types, minimum nights, reviews, and availability.

### Main Use Cases

* Compare Airbnb prices across neighbourhoods.
* Identify the most common room types.
* Understand the distribution of rental prices.
* Compare average listing prices across boroughs.
* Explore the relationship between prices and reviews.
* Improve data quality through data cleaning.

## 3. Visualization Graphs and Expected Outcomes

The project will include the following six visualizations:

### Graph 1: Listings by Neighbourhood Group

**Type:** Bar Chart

**Purpose:** Compare the number of listings in Manhattan, Brooklyn, Queens, the Bronx, and Staten Island.

**Expected Outcome:** Identify the boroughs with the highest and lowest numbers of listings.

### Graph 2: Distribution of Airbnb Prices

**Type:** Histogram

**Purpose:** Understand how listing prices are distributed.

**Expected Outcome:** Identify common price ranges and investigate unusually high prices.

### Graph 3: Price by Room Type

**Type:** Box Plot

**Purpose:** Compare prices for entire homes, private rooms, and shared rooms.

**Expected Outcome:** Understand price differences and identify potential outliers.

### Graph 4: Room Type Distribution

**Type:** Pie Chart

**Purpose:** Show the proportion of each room type.

**Expected Outcome:** Identify the most common accommodation type.

### Graph 5: Average Price by Neighbourhood Group

**Type:** Bar Chart

**Purpose:** Compare average nightly prices across the five boroughs.

**Expected Outcome:** Identify the boroughs with the highest and lowest average prices.

### Graph 6: Price Versus Number of Reviews

**Type:** Scatter Plot

**Purpose:** Explore the relationship between rental prices and review counts.

**Expected Outcome:** Investigate visible patterns between prices and reviews.

*Note: These are expected outcomes. Actual findings will be reported after analysing the dataset.*
